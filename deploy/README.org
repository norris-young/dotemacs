# Offline bundle for dotemacs

This directory builds a self-contained tarball that installs, **without network
and without sudo**, on a fresh Ubuntu 20.04 x86_64 machine:

* GCC 13.5.0 (built from its official git tag, with `jit`/libgccjit)
* CMake 4.5.0 (built from its official git tag)
* libtree-sitter 0.27.2
* Emacs 31.1 (official git tag) — **with the local tab-display fix applied
  before compilation**
* universal-ctags 6.2.1 and GNU global (latest tag)
* clangd from LLVM `llvmorg-23.1.5` (built on the target, or a bundled
  prebuilt fallback)
* the dotemacs configuration with all submodules bumped to their newest
  upstream release
* a venv for lsp-bridge using whatever =python3= the target provides
  (any Python 3; the bundled wheels are universal), and the tree-sitter grammars

## Source packaging policy

* Every compiled component that has an official git repository is shipped as a
  **depth-1 git repository tarball** (`git clone --depth 1 --branch <ref>`).
* Components without an official git repository are shipped as the official
  release source tarball. This is the case for GMP (Mercurial upstream), and
  for the GCC build prerequisites (GMP/MPFR/MPC/ISL): GCC supports them only as
  the release tarballs pinned by its own `contrib/download_prerequisites`.
* **China mirror:** GCC itself, GNU global and the GCC prerequisites
  (GMP/MPFR/MPC) are downloaded from the SJTU GNU mirror
  (=https://mirror.sjtu.edu.cn/gnu/=). GCC is therefore shipped as its official
  release tarball (=gcc-13.5.0.tar.xz=) instead of a depth-1 git repository;
  ISL is not mirrored there and still comes from
  =https://gcc.gnu.org/pub/gcc/infrastructure/isl-0.24.tar.bz2=.
* **LLVM source:** the clangd sources come from the upstream GitHub repository
  (=https://mirrors.tuna.tsinghua.edu.cn/git/llvm-project.git=, tag =llvmorg-23.1.5=), packed as
  a depth-1 git repository tarball like the other git components.
* Submodules are bumped to the newest release tag (or default-branch HEAD when
  the project has no tags) at bundle time; the private mirror is only used as a
  fallback and is recorded in `manifests/resolved.txt`.

## Build (on a machine with network access)

```sh
cd deploy
./build.sh                 # -> deploy/dist/dotemacs-offline-31.1-focal-x86_64.tar.xz
```

Options (environment variables):

| Variable | Meaning |
|---|---|
| `JOBS=N` | parallel build jobs |
| `WITH_CLANGD_PREBUILT=1` | also build a prebuilt clangd fallback (slow) |
| `DO_VERIFY=1` | run the end-to-end verification after building |
| `KEEP_WORK=1` | keep intermediate clones under `deploy/dist/work` |
| `SKIP_TOOLS=1` / `SKIP_PACKAGES=1` / `SKIP_GRAMMARS=1` / `SKIP_WHEELS=1` | skip whole phases (force) |
| `CLEAN=1` | wipe `dist/` state and rebuild everything from scratch |
| `FORCE_BUILD=1` | ignore recorded build steps and redo them |

## Install (on the offline target)

```sh
tar xf dotemacs-offline-31.1-focal-x86_64.tar.xz
cd dotemacs-offline-31.1-focal-x86_64
./install.sh               # ~1-2.5 hours; --no-clangd to skip LLVM
```

Prerequisites on the target (checked by `install.sh`): a stage0 C/C++ compiler
(`gcc`/`g++`, focal's 9.4 is enough), `make`, `autoconf`, `automake`, `libtool`,
`pkg-config`, `texinfo`, `flex`, `bison`, `bzip2`, `zlib1g-dev`,
`libncurses-dev`, `libtinfo-dev`, `libffi-dev`, `libgnutls28-dev`, `python3`,
`git`, `tar`, `xz`, and at least 25 GB of free space.

Useful options: `--no-clangd`, `--prebuilt-clangd`, `--no-native-comp`,
`--jobs N`, `--keep-build`, `--rollback`, `--purge`, `--dry-run`, `--yes`.

## What gets installed where

```
~/.local/opt/dotemacs/gcc-13.5           GCC 13.5.0 + libgccjit
~/.local/opt/dotemacs/cmake-4.5.0        CMake 4.5.0
~/.local/opt/dotemacs/emacs-31.1         Emacs 31.1
~/.local/opt/dotemacs/bin                ctags, global, clangd, dotemacs launcher
~/.local/bin/emacs                       launcher (sets DOTEMACS_OFFLINE=1)
~/.emacs.d -> ~/repos/dotemacs           the configuration (a git repository)
~/repos/mirrors                          local submodule mirrors
```

## Notes

* `DOTEMACS_OFFLINE=1` (set by the launcher) disables tree-sitter auto-install.
* Not bundled: basedpyright/Python LSP, rime, pandoc, fonts (TUI only).
* The tab fix is applied as a commit on `offline/emacs-31.1` inside the bundled
  Emacs repository; the patch and its provenance are in `repos/patches/`.

* Verified end-to-end run (this build machine)

The bundle was installed into an isolated =$HOME=/tmp/e2e/home= and passed all
self checks:

- GCC 13.5.0 built from source and installed with =libgccjit=
- CMake 4.5.0 bootstrap/configure verified (the full compile was substituted by
  the host's CMake 4.2 for time reasons; the packaged bundle still builds 4.5.0
  from source)
- libtree-sitter 0.27.2 built and installed
- Emacs 31.1 built and installed; the tab-display fix was applied with =git am=
  before =configure=
- =ctags=, GNU =global=, lsp-bridge venv (any =python3=), all 54 submodules (0
  uninitialized, clean =git status=) and 14 tree-sitter grammars installed
- =emacs --version= = 31.1; =.c= files open in =c-ts-mode=; the full
  =init.el= loads without errors

Notes from that run:

- The E2E run used =--no-native-comp= to save time. The default bundle uses
  =--with-native-compilation=aot=; its configure stage (libgccjit smoke test)
  was verified, but the full AOT compile was not run to completion here.
- =install.sh= records every completed step in
  =~/.local/opt/dotemacs/install-progress=; if a step fails (network timeout,
  missing dependency, ...) fix the cause and run the same command again: it
  retries only the failed step and everything after it. =RESUME=1= is no longer
  needed (accepted for compatibility); =FORCE_INSTALL=1= redoes all steps.
- =--with-gnutls=ifavailable= is used, so a target without gnutls-dev still
  builds (TLS support disabled, irrelevant for offline use).
- The final archive is =dotemacs-offline-31.1-focal-x86_64.tar.gz= (gzip is
  used for the outer archive because the inner component tarballs are already
  xz-compressed; this keeps packaging fast with the same size).

* Python version policy

install.sh accepts any =python3= on =PATH= (no 3.8 pinning):

- it creates the venv with =python3 -m venv --without-pip=; if the =venv= module is
  unavailable it falls back to a tiny =python3= wrapper at
  =~/.emacs.d/lsp.bridge.pyenv/bin/python= with a private =site-packages=;
- the bundled wheels are universal (=epc=, =sexpdata=, =six=, =watchdog=), so they
  load on any Python 3 (verified with 3.8 and 3.14);
- optional extras (=orjson=, =rapidfuzz=, =paramiko=) are not bundled because their
  wheels are interpreter-specific. lsp-bridge falls back to stdlib =json= without
  =orjson=; install them later with pip if you need the faster path or remote files.

* Resumable builds and installs

Both scripts persist per-step state and verify artifacts before skipping a step,
so an interrupted run can simply be re-executed with the same command line.

** build.sh

- State: =dist/work/build-state=, keyed per tool/package/grammar/wheel/patch step
  with a content signature (URL/ref/commit/manifest hash).
- On re-run, steps whose state is =ok= *and* whose artifact still exists are
  skipped without touching the network; a missing/corrupt artifact or changed
  signature causes only that step to be rebuilt.
- =CLEAN=1 ./build.sh= starts from scratch; =FORCE_BUILD=1= ignores the state.

** install.sh

- State: =$PREFIX/install-progress= (=~/.local/opt/dotemacs/install-progress=).
- Steps: gcc, cmake, tree-sitter, emacs-patch, emacs, ctags-global, clangd,
  config, python-env, grammars, launcher. Each step has an artifact check
  (binary exists and reports the expected version, imports work, every grammar
  .so is present, ...); a step marked =ok= is skipped, a =failed= step is
  retried with a warning.
- =FORCE_INSTALL=1 ./install.sh ...= redoes every step (useful after changing
  build options such as =--no-native-comp=).
- =self_check= always runs at the end, even when every step was skipped.

** install.sh must run inside the bundle

=install.sh= uses its own directory as the bundle root and verifies
=SHA256SUMS= plus =repos/*.tar=. Run it from the extracted tarball, e.g.:

#+begin_src bash
cd dotemacs-offline-31.1-focal-x86_64
./install.sh
#+end_src

Running =deploy/install.sh= from the source checkout fails with
"bundle is incomplete (missing SHA256SUMS)" by design.
